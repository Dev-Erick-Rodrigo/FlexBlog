# Flexblog

Site de blog criado como projeto prático de um curso de **Flexbox** da **Origamid**. O objetivo foi aplicar na prática os conceitos de layout flexível com CSS.

## Sobre o projeto

O Flexblog usa Flexbox para organizar o layout das páginas, de forma que o conteúdo se alinha, se distribui e se adapta a diferentes tamanhos de tela.

## Tecnologias

- HTML5
- CSS3 (Flexbox)

## O que pratiquei

- `display: flex` e eixos principal e cruzado
- `justify-content` e `align-items`
- `flex-direction` e `flex-wrap`
- `flex-grow`, `flex-shrink` e `flex-basis`
- Layout responsivo

## Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/flexblog.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
